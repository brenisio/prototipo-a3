# Protótipo A3 · Grupo F

Protótipo navegável de alta fidelidade da A3 (Síntese e Avaliação) de Engenharia de
Usabilidade, UFSC 2026/2. Redesenho do registro de refeições, Alternativa A.

**Abrir no celular:** https://brenisio.github.io/prototipo-a3/

## Fluxos

- **T1, criar conta:** Sobre você → Seu plano → Hoje (com tour de 5 passos).
- **T2, registrar o almoço:** Hoje → busca → quantidade na linha (gramas ou medida caseira) → Almoço salvo → Hoje atualizada.
- **T3, ver proteína e peso:** passos 3 e 4 do tour → Hoje.
- **Oferta do Pro (fluxo à parte):** Seja Pro → tela da oferta → confirmação.

O painel "Tarefas" inicia cada tarefa no ponto certo e conta tempo e toques. Os
resultados ficam só no navegador e podem ser copiados em texto.

Arquivo único (`index.html`), sem build. Para rodar localmente, basta abrir no navegador.
